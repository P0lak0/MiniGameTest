# Text RPG — Земли Тихого Лога

Простенькая текстовая RPG на JavaScript (Node.js), играется прямо в консоли.

## Запуск

```bash
node game.js
```

или

```bash
npm start
```

## Что есть в игре

- Свободное перемещение между деревней, лесом, пещерой и руинами
- Пошаговые бои со случайными монстрами
- Прокачка уровня, атаки, защиты и здоровья
- Лавка торговца: зелья лечения, меч, щит
- Таверна для отдыха и восстановления HP
- Простая система инвентаря

## Требования

- Node.js версии 14 и выше
